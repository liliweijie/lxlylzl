# Skill 保存规范

从现在起，每次新建个人 Skill，统一保存到用户 GitHub 仓库 `liliweijie/lxlylzl` 的 `skills/<skill-name>/`。先检查仓库现有结构、同名 Skill、本地修改和适用指令，已有同名内容应比较后更新，避免覆盖或重复创建。

每个新 Skill 必须有独立的 `中文解析/` 文件夹，包含完整中文说明、规则解析、使用方法与示例。Skill 入口用相对链接引用说明；必要的资源与机器可读示例随包保存。

完成后验证 Skill，提交并同步 GitHub，仅提交相关文件，不带入密钥或无关素材；安装到本地个人技能目录前比较已有版本。GitHub 不可用时保留本地成果并明确同步未完成，不声称已提交。遵循后续用户指定的新仓库或目录；本规范不要求迁移已有 Skill，也不授权提交无关项目。

# 完整说明与来源

这个 Skill 将商业人像和产品图中反复出现的制作决策收敛为一个入口。适用于 vivo，也能使用另一个经过用户确认的角色参考。它不自带 vivo 的私人图片，不会把旧聊天里所有服装、姿势和场景强制加到新任务。

## 工作阶段

草图阶段确认镜头、布局、动作、人物和产品尺寸。草图可以是简化的彩色摄影预览，不必变成线稿。没有选定时不自动放大、不逐个雕刻产品小字。生成工具未提供低质量参数时不能声称使用了低质量加速，也不保证草图必然更快。

选定后冻结构图底图，再按当前需求精修。用户说“只缩小瓶子”只授权瓶子及必需接触区域，不能同时更换妆容或重绘脸部。用户说“先讨论”时只解释流程。

人物的身份、当轮造型、构图底图和颜色参考各自独立。选定构图与批准永久角色参考是不同动作，文件中分别记录。

## 实际能力

- 本包提供离线原色检查和校正实现、迷宫纹检测及谱域滤波、局部修改范围检查。
- 迷宫纹脚本未附带神经网络权重，默认使用谱域回退。它与外部完整修复包的神经网络效果可能不同，检测和滤波结果均需查看。不会静默下载权重。
- 图像生成、局部重绘由会话当前可用的图像工具执行。先检查工具参数和本地图，再调用。工具不可用时明确说明，不能仅交提示词声称完成。
- SeedVR2 是可选外部放大能力，未内置模型、服务、密钥或运行环境。只有工具实际可用且获得本次素材处理授权时使用。图像生成补纹理不能记为 SeedVR2 放大或恢复相机原始细节。
- 产品精确合成需要图像编辑能力。原图像素合成适合相近角度，角度差过大不能靠二维拉伸可靠补出不可见面。生成式融合仍可能改变包装，需要逐项核验。

若当前环境要求每次编辑读取并调用已安装 image-color-guard，应遵守该项目规则。本包内附同源实现，使其他环境能独立执行，不要求重复跑两套校正。

## 依赖与公开边界

本地脚本需要 Python、numpy、Pillow、OpenCV。可复用已验证的环境，或在专属虚拟环境按 requirements.txt 安装，不能静默改全局环境。无需 API 密钥即可运行本地检查。

包内只包含规则、代码、匿名示例和来源清单。真实角色、产品素材和历史成图保留在用户授权的工作区。新 Skill 的 GitHub 同步不等于许可上传这些素材，也不自动将 vivo 写入其他角色的素材库。

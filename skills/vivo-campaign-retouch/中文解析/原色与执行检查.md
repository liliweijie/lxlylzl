# 原色与执行检查

## 固定清单

原色基准取用户确认的原始颜色主图，缺少时采用当前任务开始前的有效原图。不能把最近生成图或白模、线稿自动升级为原色主图。当前干净底图用于局部合成，身份参考用于脸型核对，产品原图用于包装核对，分别记录。

首次初始化后保留清单并每轮复用。脚本会检查原图哈希并拒绝覆盖已有清单。每次编辑前查看基准，执行后运行实际检查并打开报告与对比图。

## 本包命令

以下在 Skill 包目录运行，`python` 指已验证包含 numpy、Pillow、OpenCV 的解释器。若没有合适环境，在包外建专属虚拟环境并按 `scripts/requirements.txt` 安装。脚本不访问网络，不自动装依赖。

```bash
python scripts/guard.py init --source /absolute/original.png --manifest /absolute/color-anchor.json
python scripts/guard.py check --manifest /absolute/color-anchor.json --image /absolute/edited.png --out-dir /absolute/output/round-01
```

输出校正候选 PNG、JSON 与三栏对比。退出码 0 可能为 pass 或有意调色跳过，2 为 review，1 为输入或执行错误。必须读 JSON status。检查主体而非仅白底，阅读 `audit.before/after` 的明度差、彩度比与色差。查看对比图是独立步骤，运行成功不等于视觉通过。

有意换色区域可用 `--ignore-mask`，白色排除拟合与验收采样。它不是像素保护蒙版，校正仍可能作用到该区域。用户明确要求整体新光线或调色才用 `--mode intentional-grade`，记录跳过回色。电影级画质本身不适用此分支。

跨场景、过大透视变化或样本不足时保留 review，不按全图直方图拉亮。可额外用同场景底图做范围检查，并分别比较产品、肤色。辅助比较不能把固定原色 review 改记为通过。一次有依据的输入或蒙版修正后仍无法可靠校正时，保留候选与限制。

## 迷宫纹候选

```bash
python scripts/quality.py texture --source /absolute/material.png --allow-mask /absolute/material-allow.png --output /absolute/output/material-fixed.png --report /absolute/output/material-report.json --comparison /absolute/output/material-compare.png
```

输入为已经统一到 sRGB 的 RGB/RGBA PNG。蒙版为同尺寸 L 模式二值图，白色允许修改，黑色保护。仅在已知生成来源时传 `--model`。默认强度 35，范围 0–60，不提供强制检测通过选项。需要保护标签、手部、脸部和发丝时从允许区域扣除。

谱域滤波不能保证识别所有迷宫纹。神经网络权重未打包。脚本明确记录实际 method、decision、修改范围与输出哈希。检测 no-op 只表示未触发处理。返回 review 表示产生待目视检查的修复候选，随后仍要执行颜色检查。

## 局部范围

```bash
python scripts/quality.py scope --source /absolute/base.png --edit /absolute/final.png --allow-mask /absolute/edit-support.png --protect-mask /absolute/label-protect.png --report /absolute/output/scope.json
```

允许蒙版必须包括实际羽化过渡范围。保护蒙版白色区域优先于允许蒙版。两图需要相同画布、已经对齐、同一 sRGB 工作空间。该检查比较解码 RGBA 的实际像素，连 alpha 变化也会捕获。画布变化时先映射到最终坐标，不能把未对齐输入当作局部编辑通过。

输出包含范围外变化像素、保护区变化像素及异常包围框。0 为范围通过，2 为存在越界，1 为输入错误。范围通过不证明脸型、接触光影或包装正确。scope 无法识别被错误扩大到全图的允许蒙版，必须查看蒙版是否符合用户授权区域。

每次使用新版本输出目录，不覆盖原始文件或旧报告。先校色局部候选，再合回底图，最终再检查原色和范围。若原色候选改动了保护区，按需局部回贴并重新检查，避免用全局回色破坏局部编辑约束。

## 分开验收

分别记录身份、结构、产品、融合、颜色、纹理、修改范围和用户确认状态。某项不适用写明原因，无法验证写 review 或 not-run。不能把自动化脚本通过写成用户已经选定。版本记录示例见 [job.json](../examples/job.json)。

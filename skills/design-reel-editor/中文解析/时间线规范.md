# 时间线规范 v1

顶层：schemaVersion、profile、width、height、fps、totalFrames、loop、assets、shots。示例的素材均为虚构占位，不可直接作为已有素材渲染。

## 时间
- fps 为正数，本示例 30；帧索引为零起始整数。
- 每镜覆盖 `[startFrame, startFrame + durationFrames)`，结束帧不包含；全片为 `[0,totalFrames)`。
- startFrame 从上一镜结束累加；durationFrames > 0。展示秒数 = 帧数/fps，以帧为准。
- 关键帧 `f` 是镜头局部帧，范围 0…durationFrames-1。easing 描述从当前关键帧到下一个关键帧的插值；最后一点忽略 easing。
- 视频使用 sourceInSeconds、sourceOutSeconds（出点不包含）和 playbackRate；默认 1。必须校验源时长与镜头时长映射，源 fps 与合成 fps 不可混用。本例静帧两项为 null。

## 参数
- `assetId` 必须能在 assets 查到；`target: asset` 表示适配后的素材图层。
- `fit: contain` 先等比放入合成，scale=1 代表这个适配尺寸；百分比 = scale×100。
- `position:[x,y]` 为合成像素中的锚点位置，左上原点；`anchor:[0.5,0.5]` 为素材局部归一化中心。
- `mask` 为 null 或 `{type:"rect",rect:[x,y,width,height],space:"composition",featherPx:0}`；动画时给每个关键帧具体 mask。遮罩坐标固定在合成空间，避免被图层缩放二次影响。
- `opacity` 范围 0…1；所有静止属性也记录。示例全部无遮罩。
- easing 为 `linear`、`hold` 或 CSS 语义 `cubic-bezier(x1,y1,x2,y2)`；贝塞尔插值应按 x 求进度，不把 y(t) 直接当时间函数。
- `transitionOut` 包含 type、toShot、overlapFrames、reason。graphic-match 是硬切的视觉关系，默认 overlapFrames=0，不自动加入叠化。末镜循环指向首镜；非循环使用 end/null。

## 检查
引用存在、时间无缝且无意外重叠、总帧数一致、关键帧有序且在镜内、参数合法、视频源范围足够、遮罩与字体不误裁。允许转场重叠的扩展实现必须明确重算总时长，不能直接累加镜长。

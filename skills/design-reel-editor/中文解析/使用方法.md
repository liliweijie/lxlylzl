# 使用方法

调用：`使用 $design-reel-editor，把这些素材编排成 15 秒的 Rogue-inspired Design Reel。`

最好提供：素材文件或清单、目标平台和画幅、总时长与 fps、品牌重点、必用/禁用镜头、音乐、是否循环、Remotion 或 AE、需要方案还是最终视频。

## 常见请求
- “只有三张品牌海报，做 9 秒循环方案”：使用排版局部、遮罩和受控轻缩放；把缺失动态标为待制作，不假称已有视频。
- “把网页录屏和产品旋转视频剪成 20 秒，保留原来的字体”：根据录屏真实入出点编排，不为套风格改品牌字体。
- “只给 AE 制作表”：输出图层、帧数和关键帧映射，无须创建 Remotion 项目。

## 工作顺序
先拿到素材分析、Hero 选择与静帧顺序，再细化参数。用户已经明确要求制作时，继续制作与预览；仅要求方案时交付时间线和执行建议即可。遇到缺素材，尽量用已有素材完成可执行部分，并明确必须补齐的项目。

## 安装与维护
将整个 design-reel-editor 目录复制到个人技能目录。保留中文解析与 examples 的相对路径。未来从 GitHub 维护源同步前先比较本地变更，避免覆盖本地修订。

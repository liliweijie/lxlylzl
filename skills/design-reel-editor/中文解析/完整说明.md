# 设计型动态剪辑 Skill

本 Skill 把素材分析、Hero Frame 筛选、Graphic Match、节奏编排、Motion、切点和循环连接为一套制作流程。输出包括 Shot List、逐镜时间线、素材编号、帧数、缩放/位置/遮罩/缓动及 Remotion/After Effects 建议。

核心思路：视觉钩子 → 构图内部变化 → 信息成立 → 切换或回到钩子。剪辑顺序围绕设计的形状、排版和运动关系建立，不依赖通用转场模板。

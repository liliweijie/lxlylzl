# 跨设备项目接力

## 保存内容与规则
每份记录包含日期、项目名、工作摘要、决策、已完成事项、待办、下一步、相关线程链接、相关文件路径、Git commit 哈希与覆盖范围。日期统一按北京时间（UTC+08:00）。不保存聊天全文、源文件内容、环境变量或认证信息。空列表代表未知或没有，不代表所有内容均已扫描。

脚本只读你明确传入的摘要文件；不读取浏览器 cookie、ChatGPT 内部数据库或本地会话日志。Codex 的 list_threads/read_thread 工具能读取当前客户端提供的部分聊天；列表有数量限制，读取有分页，某些来源或设备可能不可用。不能保证列出账号全部当天聊天。自动任务应只归档能核实日期、工作进展且经过隐私检查的内容，报告缺口。

扫描器阻止常见密钥、邮箱、手机号与敏感路径，但无法识别全部公司秘密、个人隐私或新格式凭据。调用 --reviewed 表示人或当前代理已实际审阅摘要，不能仅为了通过检查而标记。疑似敏感内容保留本地并请求内容范围确认。私有仓库仍可能被协作者或组织管理员访问。

## 安装
Mac 和 Windows 均需 Python 3.9 或以上、Git、GitHub CLI。Windows 可以用 python 或 py -3，Mac 用 python3。在每台设备单独运行 gh auth login，凭据保留系统认证存储，不复制 token。

获取 Skill：

```text
git clone https://github.com/liliweijie/lxlylzl.git
```

将 skills/project-handoff 文件夹复制至 ~/.codex/skills/project-handoff；Windows 对应 %USERPROFILE%\.codex\skills\project-handoff。已有同名文件先比较，不直接覆盖。重新开启聊天后可用 $project-handoff。

获取私有记录：

```text
gh repo clone liliweijie/project-handoff
python PATH_TO_SKILL/scripts/handoff.py configure --repository liliweijie/project-handoff --checkout PATH_TO_CHECKOUT
```

将 PATH_TO_SKILL 与 PATH_TO_CHECKOUT 替换为本机真实路径；含空格路径需要引号。配置与待同步队列位于用户主目录下 .codex/project-handoff/，不进入公开 Skill 仓库。configure 不覆盖已有配置。

## 使用
在当前工作聊天说：`用 $project-handoff save 保存今天的进度。` 代理依据真实工作填写 examples/handoff.json 的字段，审查后执行：

```text
python PATH_TO_SKILL/scripts/handoff.py save --input reviewed-summary.json --reviewed
python PATH_TO_SKILL/scripts/handoff.py sync
```

换设备后说：`用 $project-handoff resume 恢复某项目，检查环境后继续下一步。` 或运行：

```text
python PATH_TO_SKILL/scripts/handoff.py resume --project 项目名称
```

resume 输出最近最多20条匹配记录，必要时代理可继续读取仓库历史文件。不会自动拉取业务源码或恢复进程。

## 每天18:15
首选当前 Codex 聊天的定时唤醒：读取可访问且确有当天工作的线程，审阅摘要、保存、运行 sync。未经读取的聊天不声称已同步。无变化不重复提交。18:15之后的工作会在下一次运行同步（保持其真实日期），或手动 sync。

已配置的定时唤醒采用当前设备北京时间。若设备时区改变，检查任务执行时间；提示中包含北京时间校验，错时不写入。机器关机、休眠、离线或应用未运行时不能保证准时执行，恢复后可手动补同步。ChatGPT 提醒可以提醒保存，但不能代替本机文件读取与 GitHub 推送。

备用系统定时方式只负责已审阅队列的 sync，不生成聊天摘要，不应与 Codex 定时唤醒同时启用：

- macOS：launchd 的 StartCalendarInterval 设 Hour=18、Minute=15，ProgramArguments 使用 Python 和脚本的绝对路径及 sync；要求系统时区 Asia/Shanghai，登录会话可访问 gh 凭据，PATH 包含 Git/gh。不要把凭据写进 plist。
- Windows：任务计划程序每日18:15，程序设置实际 python.exe，参数填写脚本绝对路径与 sync；以已登录用户运行、启用错过后尽快执行，要求系统时区 China Standard Time。仅在 Windows 设备上手工测试后启用。
- 云端 Actions 无法读取尚未上传的本机队列或全部 ChatGPT 聊天，因此未创建假同步云任务。已上传记录可云端汇总，但不改善源数据覆盖。

## 故障与恢复
私有检查、remote 校验、本地变更、锁或快进冲突失败时停止。队列在推送成功前保留。中断后检查 operation.lock 是否过期再删除；不可在另一同步运行中删除。推送失败且留下本地提交时检查该提交只含接力记录，再手动 git push；未提交变更须人工检查处理，脚本不会自动提交未知文件。不同设备冲突时人工合并，不用 force push。相同内容哈希去重，不同设备的不同摘要保留为独立记录。

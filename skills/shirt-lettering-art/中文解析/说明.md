# 印花字标

将短词、缩写、标语或名单排成可直接贴在服装上的图案。可在 Codex 中指定 `$shirt-lettering-art`，也可在 Shirt 的「印花 → AI 矢量」直接描述。网页读取同一个 Skill 包里的风格规则，并用 DeepSeek 选择造型方案。

## 使用方法

1. 把指定内容放入引号，例如「lwj」。多人名单填入「文字与排版」，一行一个名字，也可使用逗号分隔。原文、大小写和顺序交给排版器保管。
2. 说明字形和动势，例如「珊瑚红泡泡字，深蓝描边，整体向右上扬」。也可以描述笔触、材质和装饰，例如「宽头马克笔，拉一笔扫尾」。
3. 在目标颜色与位置检视。先缩到实际印花大小看轮廓和文字，再放大检查字间遮挡、孤立杂点和透明边缘。小胸标及袖口适合短字标，名单宜放在背面。
4. 只调整偏离描述的视觉参数。名单保留原顺序，短字标的字母保持正确且可读。

## 规则解析

- 泡泡字用圆鼓字形、跳跃的基线和厚边。马克笔保留笔势，用少量扫尾。喷漆用有重量的重字形和分散的喷点。贴纸用奶白切边和阴影。滴墨让墨滴从笔画下沿延伸。
- 短词采用一个视觉焦点。小装饰呼应主笔势，数量留少。图文靠对齐和色彩建立联系，给字留下独立阅读空间。
- 名单提示词按人数、印花区域和描述选择风格。手写、错落或趣味优先考虑日常签字的随意基线、收笔和少量跳色。整齐、纯文字使用平直、省装饰的方案。网站负责原文、顺序和最终的文字绘制。
- 明确要求极简、无装饰或不倾斜时优先执行。用衣服上的实际对比检查轮廓可见性；同一张图避免堆叠多种效果。
- DeepSeek 输出可校验的参数和可选矢量装饰。真正印上衣服的字符来自用户原文。离线或风格服务暂不可用时，网页按描述里的关键词完成本地排版。

## 示例

- 「把『lwj』做成珊瑚红泡泡字，深蓝描边，整体向右上扬」会采用圆鼓字形、逐字抬升和深蓝边。
- 「用钴蓝宽头马克笔写『lwj』，收笔带扫尾」会保留手写连贯感，以一笔拉出方向。
- 「把名单做成荧光绿喷漆风，印在黑衣背面，两列」会用喷点强化边缘，让名单维持规整和清晰。
- 「50 个名字做背印，深蓝手写，行宽错落，加一点跳色与手绘笔迹」会让 DeepSeek 选择马克笔、错落节奏和少量笔迹。
- 更多机器可读案例见 [examples.json](../references/examples.json)。
